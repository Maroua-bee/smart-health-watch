# smart-health-watch
Smart Health Watch project using ESP32 C3 super mini, sensors and IoT technology.

## Project Overview
Smart Health Watch is a wearable device designed to support health monitoring and personal safety, especially for elderly people and individuals at risk of falling.

## Features
- Heart rate monitoring using the MAX30102 sensor.
- Physical activity and movement tracking.
- Fall detection using the MPU6050 accelerometer and gyroscope.
- Emergency notifications through Blynk IoT.
- Health information displayed on an OLED screen.

## Hardware Components
- ESP32-C3 Super Mini
- MAX30102
- MPU6050
- 0.96-inch I2C OLED display

## Technologies
- C++
- Arduino IDE
- ESP32
- Blynk IoT
- I2C

## Future Improvements
AI integration using TinyML to recognize movement patterns, improve fall detection, and reduce false alarms.
